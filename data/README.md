# SyntheticBank-360

Synthetic enterprise dependency data for the prototype. It contains no real
customer information.

The graph represents:

Regulation → Policy → Business Process → API/Microservice → Database →
Compliance Control → Audit Artifact → Business Unit.

For a research-grade evaluation, expand the dataset with clause text, versions,
effective dates, owners, system inventory, control tests and labelled
impact/non-impact examples.
